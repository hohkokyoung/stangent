## D155 · Deterministic first: code decides everything it can, an AI only words or picks among what code laid out, and this rule wins over earlier decisions — 2026-11-07
Strengthens D18 and holds every built and planned step:
- **Code decides** whatever the code, graph or document can settle: structure, scope, bundle contents, candidates, what's missing, every id and quote.
- **An AI may only** (a) word a structure code chose, (b) pick among options code listed, or (c) make the one judgement code can't, cut as small as code can. Never "find everything" or "decide what matters".
- **Code checks every AI output;** where it can't check meaning, a person approves. A step code can do with a fixed rule or template is done by code.

- **A change to anything built or planned is said plainly, and waits for the owner's OK.** Nothing changes silently.

**Why:** hallucination can't be checked away afterwards; the less an AI decides, the less it can make up. **Cost:** more code, and blunter steps (a template reads stiffer).
